01

It knows what your files are

Filenames lie and folders get messy, so Playdex opens the file and looks instead. Headers, disc filesystems, what is sitting inside the archive. That decides the system, not the name someone typed.

02

It goes and gets the art

Box art, a description, developer, year, how many players. It starts on its own once a scan finishes, and matches on the ROM's checksum, so it does not land on the wrong game.

03

It launches what you already use

A libretro core through RetroArch, or any standalone emulator you point it at. Set that per system. If one awkward game needs something else, override that one game.

How it works

A .bin might be a PlayStation disc, or it might be an N64 cartridge.

Same story with .iso and .chd. So Playdex works down a list of evidence and takes the first thing that actually settles it.

  1. A folder you assigned You told it this folder is Dreamcast. Done, no argument.
  2. An extension only one system uses .sfc is a Super Nintendo cartridge and nothing else is.
  3. What is inside the archive A .7z is not any system. The ROM inside it is.
  4. The bytes A Wii dump has four known bytes at 0x18. A Saturn disc writes its own name into the first sector. A PlayStation 2 disc says nothing useful up front, so Playdex reads the disc's filesystem and finds the file naming its boot executable. Raw .bin tracks work too. It steps over the sync marks and error correction that a real CD carries around every sector.
  5. Folder names, then the ROM's own name Last resorts. Matched whole-word, so a game called Legbreaker does not end up filed under Game Boy.
// what a PlayStation 2 disc actually says about itself
sector 16  →  CD001    // an ISO 9660 filesystem
root dir   →  SYSTEM.CNF
SYSTEM.CNF →  BOOT2 = cdrom0:\SLUS_203.12

// BOOT2 is the PlayStation 2 key.
// plain BOOT would be the original PlayStation.

Everything gets hashed on the way in: CRC32, MD5 and SHA1, in one pass over the file. For a zipped game it is the ROM inside that gets hashed, not the zip. That is what the metadata sites and the No-Intro and Redump catalogues index, so hashing the container matches nothing at all.

Appearances

Three layouts.

Not a colour swap. A desk and a sofa want different shapes, so these are three separate layouts. Everything works the same in all of them.

Playdex

The desktop one. Systems down the side, a sortable grid, and a panel for whatever you have selected.

Console

A home screen. One row of big icons scaled to the window, with round system buttons under it.

Big Picture

For the TV. Big artwork, a rail down the left, a shelf of capsules. Run the whole thing off a controller.

Everything else

The rest of it.

Artwork and details

ScreenScraper and TheGamesDB for the text, libretro-thumbnails for the art. That last one needs no account, so it works out of the box.

Multi-disc games

Three discs, one entry in your library. Playdex writes the playlist and the emulator handles the swap when the game asks for disc 2.

Cheats

Listed per game. Flick on the ones you want and they are written where RetroArch expects them when you hit play. No extra step.

ROM hacks

Point it at an IPS, UPS or BPS patch and the result turns up as its own game. Your original ROM is left exactly as it was.

Check your dumps

Import a No-Intro or Redump catalogue and it will tell you which of your files are known-good and which are something else entirely.

Saves

Finds your saves and save states wherever the emulator buried them, and copies them somewhere safe before you go and overwrite one.

Controller

Drive the whole app from a pad. Buttons are remappable, because half the pads out there report themselves in an order of their own.

Drag and drop

Drop a ROM anywhere on the window and it is added, right where it already sits. Drop a folder and that whole folder gets scanned.

It updates itself

New versions are signed and turn up in the app. Install it once and forget about it.

Download

Try it on one folder.

One installer and not much setup. It finds RetroArch by itself if you have it, and the first scan tells you what it found and what it could not make sense of.
