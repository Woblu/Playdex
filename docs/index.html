01

It identifies your games

Filenames lie and folders get messy. Playdex reads the file itself — headers, disc filesystems, what is inside the archive — and works out which system it belongs to from that.

02

It fills in everything else

Cover art, descriptions, developer, release date, players, region. Fetched automatically the moment a scan finishes, matched on the ROM's own checksums so it lands on the right game.

03

It launches whatever you have

A libretro core through RetroArch, or a standalone emulator you point it at. Set it per system, or override it for one awkward game that needs something different.

How it works

It reads the file, not the filename.

.iso, .bin and .chd belong to a dozen systems between them, so an extension is barely a hint. Playdex works down a ladder of evidence and stops at the first rung that actually settles it.

  1. A folder you assigned If you have told it that this folder is Dreamcast, that is the end of it.
  2. An extension only one system uses .sfc is a Super Nintendo cartridge and nothing else.
  3. What is inside the archive A .7z belongs to no system; the ROM inside it does.
  4. The bytes themselves A Wii dump carries four known bytes at 0x18. A Saturn disc writes its name into the first sector. A PlayStation 2 disc says nothing at all — so Playdex reads the disc's filesystem and finds the file that names its boot executable. It does this on raw .bin tracks too, stepping over the sync marks and error correction a real CD carries.
  5. The folder names, then the ROM's own name Last resorts, matched on whole words, so a title is never mistaken for a system whose letters it happens to contain.
// what a PlayStation 2 disc actually says about itself
sector 16  →  CD001    // an ISO 9660 filesystem
root dir   →  SYSTEM.CNF
SYSTEM.CNF →  BOOT2 = cdrom0:\SLUS_203.12

// BOOT2 is the PlayStation 2 key.
// plain BOOT would be the original PlayStation.

Every ROM is hashed as it goes in — CRC32, MD5 and SHA1 in a single pass. For a zipped game the ROM inside is hashed, not the archive, because that is what the metadata databases and the No-Intro and Redump catalogues index.

Appearances

Three ways to look at it.

Not a colour swap — three separate layouts, because a desk and a sofa want different shapes. Everything works the same in all of them.

Playdex

The desktop view. Sidebar of systems, a sortable grid, and a detail panel for whatever you have selected.

Console

A home screen. One row of large icons sized against the window, and a row of round buttons underneath.

Big Picture

Living room. Hero artwork, a left rail, and a shelf of capsules. Drive the whole thing from a controller.

Everything else

The parts you only notice when they are missing.

Artwork and details

ScreenScraper and TheGamesDB for text, libretro-thumbnails for art, which needs no account at all. Runs on its own after a scan.

Multi-disc games

A three-disc game is one entry. Playdex writes the playlist and the emulator swaps discs itself when the game asks for the next one.

Cheats

Found per game, switched on where you can see them, and written where RetroArch looks for them the moment you press play.

ROM hacks

Apply an IPS, UPS or BPS patch and the result joins your library as its own game. Your original ROM is never modified.

Verify your dumps

Import a No-Intro or Redump catalogue and Playdex tells you which of your files are known-good and which are something else.

Saves

Find the save files and save states for a game wherever the emulator hid them, and copy them somewhere safe before you overwrite one.

Controller

Navigate the whole app from a gamepad, with the buttons remappable for pads that report themselves oddly.

Drag and drop

Drop a ROM anywhere on the window and it joins the library where it lies. Drop a folder and it becomes a library folder and gets scanned.

It updates itself

New versions are signed and arrive in the app. You install it once and then stop thinking about it.

Download

Point it at a folder and see.

One installer. It finds RetroArch on its own if you have it, and the first scan tells you what it found and what it could not make sense of.
