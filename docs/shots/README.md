# Screenshots

Drop PNGs in here with these names and they replace the drawings on the site
automatically. Nothing else to change — the page checks whether each file
exists and swaps it in if it does.

| File | Where it goes | Shape |
| --- | --- | --- |
| `library.png` | The big one under the hero | Wide. The whole window, around 1600×1000 |
| `skin-playdex.png` | Appearances, first card | Wide, cropped from the top-left. ~800×500 |
| `skin-console.png` | Appearances, second card | Same |
| `skin-bigpicture.png` | Appearances, third card | Same |

Anything missing just keeps its drawing, so adding one at a time is fine.

## Taking them

- Use a library with enough games to fill the grid. A screenshot of four games
  makes it look like a screenshot of four games.
- Let the metadata finish first so the covers are actually there.
- Dark background, no desktop behind it.
- The three appearance shots should be of the same library so they read as one
  app in three shapes rather than three different programs.

One thing worth knowing: box art in a screenshot is publisher artwork. Normal
enough for a project like this and everyone does it, but it is not ours, so
keep it to screenshots rather than using cover art as decoration elsewhere.
